# NextonCHF – Download

Persönlicher Finanzplaner mit **Ende-zu-Ende-Verschlüsselung** – für Windows, Mac und im Browser.

## ⬇️ Herunterladen
| System | Download |
|---|---|
| **Windows 10/11** | [NextonCHF-Windows-Setup.exe](https://github.com/armin7a/nextonchf-download/releases/latest/download/NextonCHF-Windows-Setup.exe) |
| **macOS** | [NextonCHF-Mac.dmg](https://github.com/armin7a/nextonchf-download/releases/latest/download/NextonCHF-Mac.dmg) |
| **Browser / Handy** | https://nextonchf.netlify.app |

Alle Versionen: [Releases](https://github.com/armin7a/nextonchf-download/releases)

## Installation
- **Windows:** Setup starten. Meldet Windows „Der Computer wurde geschützt“: *Weitere Informationen → Trotzdem ausführen* (die App ist nicht kostenpflichtig signiert).
- **Mac:** DMG öffnen, NextonCHF in „Programme“ ziehen. Erster Start: Rechtsklick auf die App → *Öffnen*.

## Echtheit prüfen
Jedes Release enthält `SHA256SUMS.txt`.
- Windows (PowerShell): `Get-FileHash .\NextonCHF-Windows-Setup.exe`
- Mac (Terminal): `shasum -a 256 NextonCHF-Mac.dmg`
